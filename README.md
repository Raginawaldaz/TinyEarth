# TinyEarth

一个在浏览器中运行的微型地球沙盒。基于 Three.js 渲染真实海陆分布，按经纬度与生物群系分布植被，模拟四季更替与日照变化，支持存档与加速时间。

## 功能

- **真实地球**：Blue Marble 纹理 + 地形凹凸 + 动态云层 + 极地冰盖
- **昼夜系统**：背光面保留约一半亮度的地表细节（非纯黑），叠加城市夜灯与月光；晨昏线过渡自然
- **宇宙场景**：程序化银河背景、星云、3500+ 星点；带日冕与光晕的 **太阳**、带陨石坑纹理的 **月球**（始终可见，随昼夜调整亮度）
- **植被系统**：按纬度/经度生物群系分布棕榈、阔叶树、针叶林、灌木（约数千实例，性能友好）
- **四季模拟**：南北半球季节相反，植被颜色与密度随季节变化，冰盖范围随日照角收缩/扩张
- **右上角时钟**：月份、季节、UTC 时间、昼夜阶段、日出日落
- **控制面板**（左上角）：开始/暂停、加速（1×→500×）、存档、重启
- **存档系统**：后端 REST API 持久化，手动点击存档列表加载（启动不自动读档）
- **前后端分离**：`frontend/` 纯静态页面，`backend/` Express API 服务

## 快速开始

```bash
npm install
npm start
```

浏览器打开 [http://localhost:3000](http://localhost:3000)

> **完全离线运行**：Three.js 与地球纹理均从本地加载，宇宙背景/日月为程序化生成，无需外网。

## 操作

| 操作 | 说明 |
|------|------|
| 拖拽 | 旋转地球 |
| 滚轮 | 缩放 |
| 开始/暂停 | 控制时间流逝 |
| 加速 | 循环切换 1× / 5× / 20× / 100× / 500× |
| 存档 | 保存当前游戏状态到服务端 |
| 重启 | 重置为当前真实 UTC 时间与新随机种子 |
| 点击存档项 | 手动加载存档 |

## 项目结构

```
TinyEarth/
├── backend/
│   ├── server.js          # Express 入口
│   ├── routes/saves.js    # 存档 CRUD API
│   └── data/saves/        # 存档 JSON（运行时生成）
├── frontend/
│   ├── assets/            # 地球纹理（本地）
│   ├── index.html
│   ├── css/style.css
│   └── js/
│       ├── main.js        # 入口
│       ├── earth.js       # 地球渲染与昼夜
│       ├── cosmos.js      # 宇宙背景、太阳、月球
│       ├── vegetation.js  # 植被生成
│       ├── seasons.js     # 季节逻辑
│       ├── time.js          # 时间与日出日落
│       ├── simulation.js    # 时间模拟
│       ├── ui.js            # 界面控制
│       └── api.js           # 后端通信
└── package.json
```

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/saves` | 存档列表 |
| GET | `/api/saves/:id` | 读取存档 |
| POST | `/api/saves` | 创建存档 |
| DELETE | `/api/saves/:id` | 删除存档 |

## 技术栈

- 前端：Three.js（本地 npm 包）、原生 ES Modules
- 后端：Node.js、Express
- 资源：`frontend/assets/` 本地地球纹理；宇宙/日月为 Canvas 程序化贴图

## 时间说明

- 启动时同步**当前真实 UTC 时间**
- 每天 24 小时，季节与真实日历对齐
- **1× 速度**：1 真实秒 = 1 游戏分钟（完整一天约 24 真实分钟）
